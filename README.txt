XSHOP WEBSITE — STARTER PACKAGE

Isi:
- index.html: website katalog XSHOP
- assets/xshop-banner.jpg: foto banner utama dari pengguna
- assets/xshop-robot.jpg: maskot robot XSHOP

Cara mencoba:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Tekan tombol Admin di kanan bawah.
4. PIN demo: 1234.
5. Tambahkan produk, harga, stok, dan URL foto produk.

Fitur:
- Desain responsif.
- Katalog produk tanpa kategori.
- Tombol WhatsApp untuk masing-masing admin sesuai cabang.
- Link Google Maps untuk tiga alamat cabang.
- Dashboard demo untuk menambah, mengedit, dan menghapus produk.
- Penggantian banner di browser lokal.

PENTING:
Ini adalah prototipe frontend. Data dashboard tersimpan di browser/perangkat yang dipakai saja (localStorage), bukan database online bersama.
PIN 1234 hanya PIN demo dan TIDAK aman untuk website publik.
Sebelum dipublikasikan untuk pelanggan, perlu:
- hosting + domain,
- backend/database untuk produk dan stok,
- autentikasi admin yang aman,
- penyimpanan gambar online,
- pengujian semua alamat Maps dan nomor WhatsApp.
